About Us

The AWS Club is a community of cloud enthusiasts passionate about Amazon Web Services. We aim to learn, build, and innovate together by exploring cloud technologies and applying them to real-world projects.

Club Activities

Workshops

Hands-on sessions on AWS services like EC2, S3, Lambda, and more to build practical skills.

Hackathons

Collaborative coding events where members solve challenges and create innovative cloud solutions.

Guest Talks

Industry experts share insights on cloud computing, DevOps, and emerging technologies.

Projects

Team-based projects applying AWS tools to solve real-world problems and showcase creativity.
